# おおむし.com 静的サイト

WordPress のトップページから辿れる内容を、依存パッケージなしの HTML / CSS / JavaScript で再構成しています。元サイトのロゴ・アイコンと指定された4枚のトップ画像は `assets/` に保存しています。トップ画像はページ表示時から3秒間隔で連番順に切り替わり、最後の後は1枚目に戻ります。前へ・次へ・停止・再開ボタンがあります。

## トップ画像の追加

現在は `banner-01.jpg` から `banner-21.jpg` まで連番の画像を公開しています（02番と05番は `.png`）。`assets/` に `banner-22.jpg` など次の番号の画像を追加すると、次回のページ表示から自動的に切り替え対象へ加わります。追加画像の拡張子は `.jpg`、`.jpeg`、`.png`、`.webp` に対応しています。番号は欠番なしにしてください。同じ番号で拡張子違いの画像を複数置いた場合は、上記の拡張子順で最初の画像を使用します。HTMLやJavaScriptの編集は不要です。

## ページ

- `index.html` — トップページ、連番画像が切り替わるバナー
- `about.html` — 大虫地区の概要・サイト内に保存した歴史資料、Google マップ
- `sns.html` — SNS と情報提供方法、Instagram / Facebook 埋め込み
- `archive.html` — 写真・動画アーカイブへの案内
- `assets/site.css`, `assets/site.js` — 共通スタイルと操作機能

## 広報紙おにがだけの前月号

トップページでは、閲覧時の日本の日付から**前月号**を計算し、越前市のPDFを直接埋め込みます。2026年9月号の `217.pdf` を基準として、月が一つ進むごとにPDF番号を1増やします。たとえば2026年10月中は9月号の `217.pdf`、11月中は10月号の `218.pdf` を参照します。PDFはこのサイト内に保存せず、Node.jsや定期実行は不要です。

この方法は市が毎月1件ずつ連番でPDFを公開することを前提とします。前月号が未掲載の場合や番号の付け方が変わった場合は表示できないため、トップページに[越前市の掲載一覧](https://www.city.echizen.lg.jp/office/090/030/070/24onigadake.html)へのリンクを用意しています。

## 外部サービスと残っている移行項目

Instagram / Facebook の埋め込みは各サービス側の表示設定・閲覧環境によって表示されない場合があります。SNSページに各公式ページへのリンクも用意しています。Facebook のページプラグインは `show_posts=true` を指定して公開投稿を表示します。ホームの案内ブロックでは、静的サイトだけで最新4件を安定して取得できないため、Instagramのアイコンから公式アカウントへ案内しています。

歴史資料の PDF 3点は `assets/history/` に、SNSちらしの PDF は `assets/sns-flyer.pdf` に保存しました。連絡先・住所・広報紙 URL が現行のものか、運用時に確認してください。

## 公開先

GitHub Pages で [https://kagoya.github.io/omushi/](https://kagoya.github.io/omushi/) に公開しています。公開元は `main` ブランチのルートです。独自ドメイン `omushi.com` への切り替えはまだ行っていません。

## FTP を使わない更新

GitHub にこのフォルダーを置き、Cloudflare Pages または GitHub Pages と連携すれば、GitHub への変更反映を公開に連動できます。GitHub のウェブ画面からHTMLを編集する方法もあります。`index.html` をブラウザーで開けば、サーバーへ公開する前に内容を確認できます。

大虫地区の人口・世帯数は、越前市の公表値（2026年9月1日現在）を掲載しています。越前市のページには外部サイトのJavaScriptから読み取るためのCORS許可がないため、数値は自動更新されません。更新時は[越前市の地区別人口・世帯数](https://www.city.echizen.lg.jp/office/050/130010/jinkou.html)を確認してください。
